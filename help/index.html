Démarrer

Qu'est-ce que Nidoo ?

Un écran familial pour tablette : une grille de widgets (agenda, listes de courses, menu de la semaine, routines des enfants, météo, poubelles…) que chaque famille compose elle-même, avec un côté enfant coloré et un côté parents sobre. Découvrir Nidoo.

Faut-il créer un compte ?

Non. On ouvre nidoo.latanieregeek.com dans le navigateur et on commence, sans e-mail ni mot de passe.

Nidoo est-il gratuit ?

Oui : pour l'instant, tout est 100 % gratuit et sans publicité. Certains widgets pourraient devenir payants plus tard, c'est donc le bon moment pour en profiter. Seul le widget Trafic demande une clé TomTom, elle aussi gratuite.

Sur quels appareils fonctionne Nidoo ?

Sur tout appareil avec un navigateur récent : iPad, tablette Android, ordinateur, téléphone. Il est pensé pour une tablette posée dans la cuisine ou fixée au mur ; sur un téléphone, les widgets s'affichent l'un sous l'autre.

Comment l'installer comme une application ?
  • iPad / iPhone : dans Safari, bouton Partager, puis Sur l'écran d'accueil.
  • Android : dans Chrome, menu ⋮, puis Ajouter à l'écran d'accueil.

Nidoo s'ouvre alors en plein écran, comme une application.

Comment avoir la dernière version ?

Il n'y a rien à faire : après une mise à jour, Nidoo se recharge de lui-même dans les 10 minutes. La version installée est indiquée en bas de ⚙️ Appareil (mode Modifier).

La grille

Comment ajouter, déplacer ou supprimer un widget ?

Touchez Modifier (ou faites un appui long sur la grille) : les widgets tremblent.

  • + Ajouter en haut pour en ajouter un ;
  • glissez un widget pour le déplacer ;
  • × pour le supprimer, 🎨 pour changer sa couleur, ⚙️ pour le régler.

Touchez Terminé (👍 sur téléphone) pour revenir à l'affichage normal.

Comment changer la taille d'un widget ?

En mode Modifier, touchez sa roue ⚙️ : le champ Taille propose les tailles possibles pour ce widget (1×1, 1×2, 2×2, 3×2 ou 4×2).

Je n'arrive pas à déplacer les widgets sur mon téléphone

C'est voulu : sur un téléphone, les widgets s'affichent simplement dans l'ordre, l'un sous l'autre. Rangez-les sur la tablette ou l'ordinateur.

Pourquoi la disposition n'est pas la même sur la tablette et l'ordinateur ?

La place des widgets est propre à chaque appareil (et à chaque sens, horizontal ou vertical) : ranger l'un ne dérange pas l'autre. Le contenu des widgets, lui, est bien le même partout.

Quelle différence entre le côté enfant et le côté parents ?

L'interrupteur en haut à droite passe d'une version colorée pour les enfants à une version sobre pour les adultes. Chaque côté a sa propre grille de widgets.

Pour avoir la même liste des deux côtés : en ajoutant une Liste (ou des Échéances), choisissez celle qui existe déjà de l'autre côté. Les Humeurs sont toujours les mêmes des deux côtés.

Comment changer le nom de la famille en haut de l'écran ?

En mode Modifier, touchez le nom (« Famille Dupond ») et écrivez le vôtre. Il est le même sur tous les appareils reliés.

Plusieurs appareils

Comment relier la tablette et les téléphones ?
  1. Sur l'appareil qui a la bonne grille : Modifier, puis ⚙️ Appareil, puis Afficher un code.
  2. Sur l'autre appareil : Modifier, ⚙️ Appareil, tapez le code, puis Relier.

Si les deux appareils ont déjà des widgets du même côté, Nidoo demande quelle grille garder.

Le code ne fonctionne pas

Un code est valable 10 minutes : au-delà, affichez-en un nouveau. Vérifiez aussi les caractères (il n'y a jamais de 0, O, 1, I ni L, pour éviter les confusions). Après 10 essais ratés, il faut attendre quelques minutes.

Combien de temps pour qu'une modification arrive sur les autres appareils ?

Une vingtaine de secondes en général, 5 minutes quand l'appareil est en mode nuit. Il faut que les appareils soient connectés à internet.

Deux personnes modifient la même chose en même temps : que se passe-t-il ?

Pour la plupart des widgets, la modification la plus récente gagne. Pour les Listes et les Humeurs, les deux sont gardées (par exemple deux articles ajoutés en même temps aux courses).

Comment arrêter la synchronisation d'un appareil ?

⚙️ Appareil, puis Délier cet appareil. Il garde sa grille mais ne se synchronise plus.

Les widgets

Mon agenda Google n'apparaît pas

Le widget a besoin de l'adresse secrète au format iCal de l'agenda (l'adresse publique ne marche que si l'agenda est public) :

  1. Dans Google Agenda sur ordinateur, ⚙️ Paramètres ;
  2. à gauche, l'agenda voulu, puis Intégrer l'agenda ;
  3. copiez l'Adresse secrète au format iCal et collez-la dans le réglage ⚙️ du widget Agenda.

Les nouveaux rendez-vous apparaissent dans les 10 minutes ; la flèche ↻ du widget les relit tout de suite. iCloud et Outlook fonctionnent aussi.

Le minuteur ne sonne pas

Les navigateurs n'autorisent le son qu'après un toucher : démarrez le minuteur avec le bouton ▶ (pas seulement avec +). Vérifiez aussi le volume de la tablette et, sur iPhone ou iPad, que le mode silencieux n'est pas activé.

L'écran de la tablette se met en veille

Pendant qu'un minuteur tourne, Nidoo empêche la mise en veille. Le reste du temps, c'est le réglage de la tablette qui décide : sur iPad, Réglages, Luminosité et affichage, Verrouillage automatique (« Jamais » pour une tablette au mur). Le mode nuit de Nidoo assombrit l'écran aux heures choisies.

Comment gérer les semaines A et B dans l'emploi du temps ?

Dans la ⚙️ du widget, réglez Semaines A et B avec n'importe quel jour d'une semaine A. Dans les cours, mettez A: ou B: devant ceux qui n'ont lieu qu'une semaine sur deux (ex. A: 14h Piscine). Tous les détails dans la documentation.

Le menu de la semaine propose des plats que nous ne mangeons pas

Dans la ⚙️ du widget, ajoutez les aliments interdits (un par ligne : champignons, porc, végétarien, sans gluten…). Pour un seul plat, la flèche ↻ de sa ligne en tire un autre au hasard. Pour une allergie grave, vérifiez toujours les ingrédients réellement utilisés.

Comment envoyer les ingrédients du menu dans ma liste de courses ?

Il faut une Liste nommée Courses. Dans le menu, touchez 🛒, cochez les ingrédients voulus, puis Ajouter à la liste des courses. Les quantités tiennent compte du nombre de personnes réglé dans ⚙️.

Un widget affiche « Pas de connexion » ou reste vide

La météo, Tempo, le pollen, les carburants, le trafic et les agendas ont besoin d'internet. Vérifiez le Wi-Fi de la tablette ; le widget se remet à jour tout seul au retour de la connexion. Pour la météo et le pollen, vérifiez aussi l'orthographe de la ville dans ⚙️.

Le widget Trafic montre un exemple

Il lui faut une clé TomTom, gratuite : créez un compte sur developer.tomtom.com, copiez la clé (« API key ») du tableau de bord et collez-la dans la ⚙️ du widget, avec vos adresses de départ et d'arrivée.

Données

Où sont gardées mes données ?

Dans le navigateur de l'appareil. Si vous reliez plusieurs appareils, la grille est aussi enregistrée sur le serveur de Nidoo, dans un fichier accessible uniquement avec la clé secrète de votre famille. Les adresses d'agenda et la clé TomTom en font partie.

Comment tout effacer ?

Sur un appareil : supprimez les widgets en mode Modifier, ou effacez les données du site dans les réglages du navigateur (sur iPad : Réglages, Safari, Avancé, Données de sites web).

Si vos appareils étaient reliés et que vous voulez aussi effacer la copie gardée sur le serveur, écrivez-nous.

J'ai changé de tablette : comment retrouver ma grille ?

Si l'ancienne tablette (ou un téléphone) est toujours reliée, affichez un code dessus et reliez la nouvelle : elle reprend la grille. Sinon, il faut recomposer la grille : sans appareils reliés, les données restent dans le navigateur de l'ancien appareil.
